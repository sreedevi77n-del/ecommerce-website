# 🌸 Flower Shop Website

A modern and responsive **Flower Shop Website** designed using HTML5 and CSS3. This project focuses on creating a clean, visually appealing, and user-friendly interface for showcasing flowers and related products.

## ✨ Features

* Responsive and user-friendly design
* Clean navigation bar
* Attractive flower product sections
* Product cards with images and details
* Well-structured layout
* Contact section
* Modern CSS styling
* Mobile-friendly design

## 🛠️ Technologies Used

* **HTML5** – For creating the structure and content of the website
* **CSS3** – For styling, layout, responsiveness, and visual design
